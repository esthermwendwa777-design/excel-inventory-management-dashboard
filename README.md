# Inventory Management & Stock Analysis Dashboard

## Project Overview

This project involves analysing a fictional business inventory dataset using Microsoft Excel. The aim is to monitor stock levels, calculate the value of available inventory, identify products requiring restocking, and present findings through a dashboard.

## Project Objectives

- Track remaining stock for different products.
- Calculate the monetary value of available inventory.
- Identify products that have reached their reorder levels.
- Analyse inventory value across different product categories.
- Visualise inventory performance using charts and a dashboard.

## Tools Used

- Microsoft Excel

## Excel Skills Demonstrated

- Data entry and formatting
- Excel formulas and functions
- IF statements
- SUM and SUMIF
- COUNTIF and COUNTA
- Inventory calculations
- Conditional analysis
- Data visualisation
- Dashboard creation

## Key Findings

### Inventory Summary

| Metric | Result |
|---|---:|

| Products Needing Restock | 10 |

| Total Products | 12 |

### Inventory Value by Category

| Category | Inventory Value |
|---|---:|
| Electronics | KES 1,193,500 |
| Groceries | KES 17,250 |
| Furniture | KES 482,500 |
| Stationery | KES 22,500 |

### Key Business Insights

- Electronics account for the largest share of inventory value.
- 10 out of 12 products have reached or fallen below their reorder levels.
- Only 2 products currently have sufficient stock.
- The business should review its stock levels and prioritise products requiring restocking.

This project provided practical experience in using Microsoft Excel to analyse inventory data, automate stock monitoring, calculate inventory value, and communicate business insights through visualisations.
